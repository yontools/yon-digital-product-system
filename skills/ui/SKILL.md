# UI

## Objetivo
Construir interfaces claras, consistentes y visualmente profesionales.

## Revisar

- tipografía
- escala visual
- espaciado
- contraste
- componentes
- estados interactivos
- iconografía
- jerarquía
- responsive
- consistencia entre páginas

## Regla visual

La interfaz debe explicar qué importa primero, qué puede hacerse después y qué ocurrió después de cada acción.

Evitar decoración sin función. El estilo debe servir a la comprensión y a la identidad del producto.
