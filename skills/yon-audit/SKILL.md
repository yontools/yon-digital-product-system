# YON Audit

Apply the YON loop to an existing product. Inspect before judging. Understand users and critical workflows. Detect friction, missing states, inconsistency, accessibility and responsive issues, performance risks, repetitive operator work, and automation opportunities. Prioritize by impact, confidence, and effort. Do not modify files unless the user explicitly asks for implementation.

If the environment allows it, run the product and inspect the affected flows in the browser. Report evidence, severity, recommended change, and how to verify each important finding.
