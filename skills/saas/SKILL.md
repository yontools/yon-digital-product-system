# SaaS

## Objetivo
Diseñar sistemas que permitan a personas y organizaciones completar operaciones reales de forma eficiente y sostenible.

## Fundamentos

- roles y permisos
- onboarding
- navegación
- dashboard
- CRUD
- búsqueda y filtros
- tablas
- formularios
- estados y workflows
- notificaciones
- actividad e historial
- configuración
- billing cuando corresponda
- seguridad
- responsive

## Operación

Identificar las tareas que se repiten y priorizar automatización, acciones masivas, valores por defecto, atajos y contexto relevante.

## Principio

Un SaaS profesional no es solamente un conjunto de pantallas: es un sistema operativo para un proceso de negocio.
