# YON Onboarding

Identify the user's first valuable outcome and the minimum information required to reach it. Prefer progressive setup, useful defaults, imports, contextual guidance, and real first-task completion over long tutorials. Allow users to continue later when appropriate. Verify the complete first-run journey, including loading, validation, errors, empty states, and mobile behavior.
