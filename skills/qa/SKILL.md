# QA

## Objetivo
Verificar que el producto funcione y que la experiencia final sea coherente con lo diseñado.

## Loop

`RUN → INSPECT → CORRECT → VERIFY`

## Checklist

- rutas y navegación
- formularios
- validaciones
- estados de carga
- errores
- permisos
- responsive
- accesibilidad
- consola
- performance
- acciones críticas
- casos límite

## Regla

No considerar terminado un cambio solamente porque compila. Hay que probar la experiencia real en el navegador y revisar visualmente las superficies afectadas.
