# YON QA

Run the affected product and exercise the real user journey. Check navigation, forms, validation, loading, empty, success and error states, permissions, responsive behavior, accessibility, console/runtime errors, performance, critical actions, and edge cases. Correct issues discovered during inspection and rerun verification. A successful build is not sufficient evidence of completion.
