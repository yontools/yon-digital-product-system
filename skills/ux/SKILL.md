# UX

## Objetivo
Hacer que las tareas importantes sean fáciles de descubrir, comprender y completar.

## Auditoría UX

Revisar:
- navegación
- jerarquía
- cantidad de clics
- formularios
- feedback del sistema
- errores
- estados vacíos
- búsqueda y filtros
- acciones frecuentes
- responsive
- accesibilidad

## Regla

Si una acción frecuente requiere pasos innecesarios, buscar una forma de acercarla al contexto donde el usuario la necesita.

## No asumir

Antes de cambiar un flujo, identificar su propósito y restricciones. Una aparente fricción puede ser una protección, requisito operativo o regla de negocio.
