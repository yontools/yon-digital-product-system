# YON Web

Start from the site's purpose, audience, primary actions, content hierarchy, and conversion or information goals. Inspect existing routes and components before changing them. Design responsive behavior intentionally, use visual assets when they improve communication, avoid generic decoration, and verify navigation, forms, states, accessibility, and performance in the running site.
