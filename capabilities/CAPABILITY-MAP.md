# YON Capability Map

This map helps YON recognize reusable capability combinations when planning a new product.

## Operational asset SaaS

`Asset Management + Workflow Engine + Geolocation & Tracking + Temporal States & Expiration`

Useful for products managing physical resources through operational lifecycles.

## Rental SaaS

`Asset Management + Rental Management + Temporal States & Expiration + Notifications`

Useful when resources are assigned temporarily and deadlines drive operations.

## Field operations

`Asset Management + Geolocation & Tracking + Workflow Engine + Notifications`

Useful when distributed teams need location-aware operational workflows.

## Rule

These combinations are starting hypotheses, not automatic architecture decisions. YON must still inspect the specific product, users, constraints, and existing code before selecting or implementing capabilities.

## Privacy

This map contains only generalized capability relationships. It must not be populated with private project implementation details.
