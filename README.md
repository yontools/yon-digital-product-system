# YON Digital Product System

Sistema abierto de metodología, patrones y herramientas para diseñar, construir, mejorar y verificar productos digitales.

## Propósito

Crear productos digitales más simples, útiles, claros, accesibles y agradables de usar: desde una landing page hasta un SaaS completo.

## Principio central

> No modificar por modificar. Mejorar aquello que realmente mejora la experiencia, el resultado o la operación del usuario.

## Flujo

`OBSERVE → UNDERSTAND → DETECT → PROPOSE → IMPLEMENT → RUN → INSPECT → CORRECT → VERIFY`

## Evolución comunitaria

El sistema puede evolucionar mediante contribuciones, nuevos patrones, experimentos y feedback. Las mejoras deben revisarse y versionarse; no existe aprendizaje automático silencioso que exponga código, datos o conocimiento privado.

Estados de patrones:

- `proven` — probado y recomendado
- `experimental` — en evaluación
- `deprecated` — reemplazado o no recomendado
