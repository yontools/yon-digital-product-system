# /yon-visual

## Purpose
Improve the visual communication and perceived quality of a digital product without sacrificing usability.

## Review

- visual hierarchy;
- typography;
- spacing and rhythm;
- contrast;
- component consistency;
- imagery;
- iconography;
- empty and error states;
- responsive composition;
- motion opportunities;
- brand coherence.

## Rules

Visual polish must reinforce comprehension, trust, identity or feedback.

Prefer purposeful imagery and custom visual direction when generic assets weaken the product's message.

Motion should communicate state, hierarchy or continuity. Avoid animation that slows users down or distracts from important work.

Always verify the visual result in the running application, including relevant mobile widths.
