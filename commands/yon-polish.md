# /yon-polish

## Purpose
Improve an existing product without blindly redesigning it.

## Instructions

Follow the YON operating loop:

`OBSERVE → UNDERSTAND → DETECT → PROPOSE → IMPLEMENT → RUN → INSPECT → CORRECT → VERIFY`

Before editing:
- understand the current behavior;
- identify the target user and task;
- preserve working business rules;
- choose improvements with meaningful user impact.

During editing:
- prefer coherent, focused changes;
- reuse established components and patterns;
- improve hierarchy, clarity, feedback and interaction quality;
- handle loading, empty, error and success states;
- consider responsive and accessibility behavior.

After editing:
- run the product;
- inspect affected flows in the browser;
- check for runtime/console problems;
- verify that the intended improvement actually exists;
- correct regressions before declaring completion.

## Output

Summarize what changed, why it changed, what was verified and any remaining risks.
