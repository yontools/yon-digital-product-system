# /yon-web

## Purpose
Build or improve a professional website with a strong information architecture, visual identity and responsive experience.

## Instructions

- Understand the audience and primary conversion/communication goal.
- Establish clear navigation and page hierarchy.
- Design reusable layout and component patterns.
- Use typography, spacing and imagery intentionally.
- Avoid generic template-like presentation when bespoke direction would better communicate the brand.
- Include meaningful states and interactions where applicable.
- Consider SEO, accessibility, performance and mobile behavior.
- Run and inspect the website before completion.

Do not add visual effects merely to make a page look busy. Motion must support hierarchy, feedback or storytelling.
